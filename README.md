# AI-Powered AR Virtual Try-On with Personalized Style Compatibility Index (PSCI)

## Project Overview
This project presents an AI-powered Augmented Reality (AR) Virtual Try-On system that allows users to visualize outfits, estimate body measurements, receive personalized hairstyle and accessory suggestions, and obtain a Personalized Style Compatibility Index (PSCI).

The system integrates computer vision, machine learning, body measurement estimation, and personalized fashion recommendation techniques to enhance the virtual shopping experience.

## Key Features

- **AR Virtual Try-On:** Visualize clothing on the user's body.
- **Smart Body Measurement:** Estimate body measurements using camera-based scanning or manual input.
- **AI Personal Stylist:** Analyze facial shape and suggest suitable hairstyles and accessories.
- **Personalized Size Recommendation:** Recommend suitable clothing sizes.
- **PSCI:** Calculate a personalized style compatibility score based on multiple style factors.
